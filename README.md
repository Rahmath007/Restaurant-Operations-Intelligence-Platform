# Restaurant Operations Intelligence Platform

## Project Overview

This project simulates a real-world analytics solution for a multi-branch restaurant chain. The goal is to reduce manual reporting, improve operational decision-making, forecast demand, identify food waste risks and support better staffing decisions.

## Business Problem

Restaurant managers often rely on manual spreadsheets to track daily sales, staffing, waste and inventory. This can take several hours per week and makes it difficult to identify problems early, such as overstaffing, understaffing, high waste levels or low-performing products.

## Project Objective

The objective of this project is to build an end-to-end analytics platform that:

- Automates data cleaning and reporting
- Stores clean operational data in PostgreSQL
- Uses SQL to calculate business KPIs
- Uses Python to analyse trends and forecast demand
- Uses Power BI to create interactive dashboards
- Provides actionable recommendations for managers

## Tools Used

- Python
- pandas
- PostgreSQL
- SQL
- Power BI
- Excel
- GitHub

## Key Business Questions

- Which branches generate the most revenue?
- Which products create the most waste?
- When are branches overstaffed or understaffed?
- What are the busiest days and hours?
- Which menu items should be ordered more or less?
- Can future demand be forecasted?
- How much reporting time can be saved through automation?

## Expected Business Impact

This project aims to demonstrate how analytics can save time, reduce waste, improve labour planning and support better decision-making in a restaurant business.
